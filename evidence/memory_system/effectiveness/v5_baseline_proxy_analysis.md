# v5 Baseline + Memory-On Proxy Signal (interim, 2026-06-11)

Aggregation of the per-game de-lucked proxies (`computed_metrics`) across the v5 seeding run.
**Directional / hypothesis-generating only** — the memory-ON arm is the v5_1 *build* games
(`all_enabled`, unpaired, growing store, rerank/filter OFF = raw top_k=3), NOT the clean paired A/B.
Treat as a pilot for Phase C sizing + demonstrator-role selection, not as the effect itself.

## Arms
- **memory-OFF (N=30):** v5_0 seeding (20 `all_disabled` extraction-on) + 10 extraction-off baseline pad.
- **memory-ON (N=20):** v5_1 build games (`all_enabled`, rerank/filter OFF), batches b1–b4.
- Classified per-record by `memory_config` (not filename).

## ⭐Key read (revises the headline): wolves win via DEGRADED TOWN PLAY, not better wolf deception
The proxies converge on a coherent — and counter-intuitive — story:
- **Town roles play WORSE under memory:** mislynches +0.35, correct_elimination −0.16,
  wolf_elimination −0.18, vigilante_correct_shot −0.29 (+ friendly-fire +0.22), investigator_found_wolf
  −0.36 / wolves_found −0.18. Town votes + vigilante shots + wolf-catching all degrade.
- **Wolf deception proxies also DROP:** wolf_steering −0.33, wolf_blending −0.17. So wolves are NOT
  winning by deceiving better.
- ⇒ The +33pp wolf win-rate is most consistent with **memory degrading TOWN decision-making → wolves
  win by default**, NOT with memory empowering wolves. This **supports the retrieval
  distraction/overload hypothesis** — and v5_1 ran **rerank/filter OFF (raw top_k=3)**, exactly the
  uncurated condition that would distract.
- The one apparent positive: investigator_threat_find_lift +0.34 — memory *does* feed better
  threat-finding, but it's **not converting** to wolf-eliminations (town can't act on it). Signal that
  retrieval helps perception but raw/uncurated context hurts the downstream decision. ⚠️ Hypothesis
  only: the investigator proxies failed monotonicity validation (lift is ~uncorrelated with villager
  win on these games — see proxy validation status above), so "helps perception" has no validated
  outcome anchor yet.

## ⭐Phase C implications
1. The headline is likely "**raw memory distracts the town**," not "memory helps wolves" — a critical
   distinction. The clean A/B MUST include a **memory-on-RAW (top_k=3) vs memory-on-RERANKED/FILTERED**
   arm to separate "memory distracts" from "memory helps when curated."
2. Investigator remains the cleanest *perception* beneficiary (threat-find lift), but decision-quality
   proxies (vote accuracy, wolf-elim) are the ones that move win-rate — size the A/B on those.

## Caveats (do not over-read)
- Confounded: unpaired build games, growing store, rerank/filter OFF, unequal/small N (30 vs 20),
  population sd shown. Several proxies have small sub-N (wolf_blending 14/6, wolf_steering 12/12).
- Next: the clean **frozen-store** memory-on run (constant treatment, N≈30) — and ideally **paired**
  (same `game_id` on/off → McNemar). Re-derive proxies on that; this pilot only points the way.
  See `report.md` statistical design + [[project-metrics]].
