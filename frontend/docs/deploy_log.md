# Deploy log: wolf.liuhaochen.com

Status (2026-10-26): a journey log, kept whole. It grew inside `build_plan.md` §7 from the first
deploy on 2026-08-21 to 2026-10-22 and was lifted here unchanged on 2026-10-26, one entry per
paragraph under its date. New deploys are appended at the end.

An entry records which containers were rebuilt and at which commit, the rollback image, what the
deploy carried and why, the checks run before the swap, and the smoke after it. The three things
the first deploy surfaced (Cloudflare buffering the stream, credentials needed even for replays, the
memory store mount) are in `build_plan.md` §7, "Deploy notes"; the server's side of the incidents is
in [`server_encountered_challenges.md`](server_encountered_challenges.md).

**The procedure the entries settled into.** Read across the entries; no document rules it.

- Build from a clean detached worktree at the commit being deployed, so uncommitted work stays out
  (from 2026-09-17; 28 entries say so).
- Keep the image that ran before as `:prev`; rollback is swapping it back (named in 70 of 72 entries).
- A migration runs first, from inside the new server image on the `werewolf` network: the host cannot
  resolve the database's name and the old image lacks the migration file (2026-09-17).
- Pre-flight in the new image with the production settings before the swap (8 entries, from 2026-09-17).
- Swap only with no room waiting and no game live; a deploy that found a human game running waited
  for it to finish (stated from 2026-10-16).
- Smoke after the swap: the site's pages, the API's health, models and replays, and one game or
  replay through the browser (66 entries).
